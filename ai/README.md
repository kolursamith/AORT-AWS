# ai/

**Owner: Owner A · Phase 7 — AI prediction · Status: not started**

Anomaly detection and failure/impact prediction.

Planned starting point: Isolation Forest for anomaly detection and Random
Forest for failure classification, with XGBoost only if results justify it.
Deliberately **not** starting with LLMs, reinforcement learning or deep
learning — the dataset is small and the models must stay explainable.

Depends on the Phase 6 dataset, which must come from real controlled runs.
