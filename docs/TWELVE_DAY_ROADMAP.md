# Twelve-day course roadmap

| Day | Integrated outcome |
|---|---|
| 1 | Contracts, repository governance, independent runnable skeleton |
| 2 | Hackathon vertical slice and basic metrics |
| 3 | PostgreSQL migrations, authoritative evidence adapter, outbox worker |
| 4 | Finite queue and workload/fault distributions |
| 5 | Static, immediate, backoff, AIMD, and proportional baselines |
| 6 | Route/transaction twin calibration and error reporting |
| 7 | Capacity/resolution models compared with EWMA/non-ML methods |
| 8 | Counterfactual optimizer, deadline ranking, invariant gate |
| 9 | Flooding/poisoning/replay matrix and conservative fallbacks |
| 10 | Repeated seeds, ablations, confidence intervals, figures |
| 11 | Reviewed AWS deployment, observability, teardown drill |
| 12 | Reproduction run, report, demo, limitations, submission |

Each day ends with a reviewed PR to `developer`; only green, integrated milestones promote to `main`.
