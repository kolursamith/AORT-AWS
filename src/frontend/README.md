# Frontend (Phase-II)

Planned web interface for the AORT Decision Dashboard.

## Planned Implementation

| Component | Description |
|-----------|-------------|
| Twin Status View | Live operational digital twin health and dependency graph |
| Scenario Panel | Select and run multi-hazard disaster scenarios |
| Prediction View | AI-generated disruption forecasts and affected services |
| Recovery Ranking | Compare ranked DR plans (RTO, RPO, cost, compliance) |
| Approval Workflow | Administrator approve/reject recovery recommendations |
| Compliance View | Audit trail and policy validation status |

## Planned Technology

- React.js (or equivalent SPA framework)
- REST API integration via API Gateway
- Amazon CloudFront for static asset delivery

## Phase-I Status

No code — planning only. Implementation begins in Phase-II.
